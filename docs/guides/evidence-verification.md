# 离线核验证据归档

取得 `COREPILOT_EVIDENCE_JSON_GZIP_V1` 文件后，从可信渠道另行取得该文件的 **archive SHA-256**，在安装了 CorePilot 的机器执行：

```text
corepilot evidence verify ./evidence.json.gz --sha256 <可信渠道提供的归档SHA256> --json
```

这条命令无需连接 CorePilot 服务、模型或 Runner。它不解包到文件系统，也不执行包内脚本。输出是 JSON；成功时 `ok` 为 `true`，退出码为 0；失败时退出码非 0，使用 `--json` 时错误以 JSON 输出到标准错误。

核验内容包括提供的归档 SHA-256、内置清单摘要、每个归档文件的长度和 SHA-256、文件名安全、证据记录类型，以及证据中任务、候选、提交、正式实验与复验的指定身份关联。旧版证据记录未单独写入 Candidate tree 时，输出会明确列出该字段尚未由证据记录绑定。CLI 不输出源码、命令日志或整个原始 JSON。

应使用 `snapshot.artifact.archive_sha256`，不是 `snapshot.artifact.digest`（后者是文件清单摘要）。已连接服务的用户可用 `corepilot workflow evidence <workflow-id> --output <文件> --json` 下载并查看该字段；在跨边界交付时，预期归档 SHA-256 仍应由审阅者通过可信渠道独立取得。

当前离线入口最多读取 **256 MiB 压缩包、512 MiB 解压后 JSON、25000 个文件**。超过上限会停止核验，不表示归档无效。现有服务端审批仍使用原目录核验，历史格式的读取语义保持不变。

完整性一致不代表内容或来源可信，也不代表统计方法、实验有效性、目标机器执行、人工批准或交付已通过核验。冻结归档产生于批准之前，不包含之后的审批决定。归档可能包含源码、机器信息、命令输出和其他敏感数据；本命令不做脱敏，成功也不意味着归档可以公开。CorePilot 当前没有通用的公开脱敏证据包。

## 离线重算性能统计

对包含冻结测试方案及两轮原始样本的 V1 归档，可在同一命令中要求重新计算：

```text
corepilot evidence verify ./evidence.json.gz --sha256 <可信渠道提供的归档SHA256> --recalculate-performance --json
```

此选项先执行上述完整性与身份核验，校验归档中冻结测试方案的摘要，再使用 CorePilot 的 `paired-block-bootstrap-v1` 方法，分别重算正式实验与独立复验的原始样本，并与两轮各自保存的统计结果比较。不会提取或运行归档中的脚本，也不会连接服务或机器。输出中的 `formal` 和 `revalidation` 分别列出状态及重算得到的总体统计值，不能合并两轮样本或挑选较好的一轮。

`performance_recalculation.status` 和各轮状态有以下含义：

| 状态 | 含义 |
| --- | --- |
| `MATCH` | 按归档中的固定方案重算，与该轮保存的性能统计数值一致。 |
| `MISSING` | 缺少重算需要的记录。 |
| `LEGACY` | 历史 v2 方案可能使用外部提供的下界，无法仅从样本重算为 v3 区间。 |
| `UNSUPPORTED` | 此版本不支持记录的方案版本或统计方法。 |
| `INVALID` | 重算输入、样本或身份字段格式无效。 |
| `LIMIT_EXCEEDED` | 输入或计算规模超过离线工具上限，不代表原实验无效。 |
| `INCONSISTENT` | 冻结方案、样本、实验身份或保存的结果之间存在不一致。 |

带此选项时，两轮均为 `MATCH` 才返回 `ok: true` 和退出码 0；若归档完整性核验通过但重算无法确认一致，返回 `ok: false` 和退出码 2，结果中保留各轮状态。归档完整性或命令参数错误仍以非零退出码和错误信息报告。

为避免对不可信归档进行无界计算，离线重算最多接受 64 个负载、每角色每负载 1000 个样本，`负载数 × 每角色样本数 × 重采样次数` 不超过 1000 万；冻结方案最多 4 MiB，每轮原始测量文件最多 32 MiB，JSON 嵌套深度最多 64。工具的限制不改变实验本身或冻结方案。

结果一致仅说明归档内的记录能按保存的方法重现同一数值；它不能证明样本来自目标真机、测试方案已获资格、统计假设成立、测量资源有效、正确性通过或结果获批。归档不包含可独立验证的全部二进制原件，评价器与 benchmark 的部分身份由执行程序自报；核验不能据此确认实际执行的二进制。归档摘要需要从独立可信渠道获取，本工具不承担来源认证或公开脱敏。
