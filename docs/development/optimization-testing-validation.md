# 优化与测试分离的验证记录

日期：2026-11-09。范围和实现边界见[交互设计](../design/optimization-testing-separation.md)、[使用指南](../guides/optimization-and-testing.md)和[系统架构](../architecture/corepilot-system.md)。

## 已检查的行为

| 路径 | 验证与结果 |
| --- | --- |
| 仅生成源码 | 使用真实 Control HTTP、Git、SQLite 和 Pi 协议夹具，从没有测试方案或构建命令的项目生成冻结候选；零 Runner 实验，原始分支未修改。报告与界面明确未验证；批准和正式交付被拒绝。 |
| 候选进入测试 | 浏览器创建源码任务、查看真实补丁，再进入独立测试；传递候选 commit，未误测原分支 HEAD。 |
| 三种比较组合 | 离线 Runner/传输夹具覆盖源码与源码、源码与文件、文件与文件；两端工作目录和依赖路径独立，项目基线、oracle 与方案资格没有被覆盖。 |
| Web 与 CLI | 真实 HTTP 入口和 CLI 读取同一测试、库包、测量及取消状态；文件对文件不依赖源码项目，也不调用模型。 |
| 恢复与幂等 | 相同请求返回原测试；条件冲突拒绝；提交结果未知只查询原 ID。准备中断、取消请求与确认停止分别验证，机器连接变化不能把查询切换到另一 Runner。 |
| 配置与布局 | 方案摘要与提交 digest 一致；构建覆盖、错误校验、草稿恢复、返回测试准备、目录刷新及失败重读可用。1440、1280 和窄屏布局无页面横向溢出，1280×720 下弹窗主操作可见。 |
| 结果语义 | 执行完成、正确性、性能变化、批准及交付分开显示；缺失、重复或无效测量不能变成通过。无统计规则只报告点估计，不制造置信区间。 |

## 本轮没有证明的能力

本轮未调用实际付费模型，未在远程机器运行优化、构建或性能测试，未执行真实批准、合并或交付。测试服务使用离线 Runner 和传输夹具验证编排；已有 Runner 执行器的本地命令、资源、协议及恢复测试包含在仓库回归中。这里不据此宣称新 CPU、库包或脚本已经在真机取得性能收益。

独立测试当前复用已有 Package/Evaluator；库包入口支持 Linux `.so` 与头文件。无源码项目时可比较已有库包，但尚无脱离库接入上下文的 AI 方案生成入口；独立测试结果不会自动取得正式优化批准资格。前端构建仍提示主 JS 分块超过 500 kB，后续是否拆分应结合实际加载测量决定。
