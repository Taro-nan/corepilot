## 本轮实施与验证

### 本机配置跟踪

- **原始问题**：根目录 `corepilot.yaml` 与 `.tmp-model-test/config.json` 原本已被 Git 跟踪，后者即使位于忽略目录仍会进入克隆；前者含机器专用配置。
- **决策和修改**：仅从当前索引移除两项，保留原本地文件；`.gitignore` 忽略根配置，`scripts/check-repository.mjs` 拒绝跟踪配置、运行数据和临时模型测试目录，公共示例保留在 `examples/`。
- **针对性测试**：`node --import tsx --test --test-concurrency=1 tests/repository-hygiene.test.ts`，3 项通过；测试使用隔离 Git 仓库验证强制加入本机配置会失败、移出索引后原文件仍存在。
- **限制**：当前分支的删除不会清除既有 Git 历史或已推送副本；本次不擅自重写历史。

### 候选源码符号链接

- **原始问题**：`WorkspaceToolset` 检查中间目录链接，却允许最终路径为符号链接；读写最终链接可能访问工作区外的文件，包括独立 oracle。失效链接因 `existsSync` 返回 false 也未被识别。
- **修改**：所有路径分量使用 `lstatSync` 检查，包括最终分量和失效链接；现有的源码范围检查继续执行。
- **针对性测试**：`node --import tsx --test --test-concurrency=1 tests/workspace-tools.test.ts tests/library-package.test.ts`，24 项通过。本机 Windows 测试末尾和中间目录 junction 及外部文件保持不变；普通文件链接和失效文件链接已编写 Linux 测试，尚待执行，本机没有创建文件符号链接的权限。
- **限制**：这是应用层路径约束，不能防止其他进程在检查与使用之间替换路径，也不能约束任意构建命令。需要系统级资源/权限隔离才能进一步收紧这些边界，不能把本次修复称作完整沙箱。

### 实验结果与统计规则的核对

- 发现冻结证据前只核对性能样本数量、身份和正值，可能把数值已变化的样本与旧的通过结论一起打包。冻结、人工批准和交付前现按正式与复验各自保存的样本、冻结方案和门禁版本重算；混入其他轮次、额外样本、变更统计摘要均会阻断新批准。
- 执行与证据复核共用方案兼容性规则，除清单、参数及采样外，还核对资源、关键负载、权重和 evaluator 内冻结的统计方案。新批准要求 v3 真实区间；旧点估计实验保留，已有历史批准按原口径读取并单独核验。`tests/testpack-compatibility.test.ts`、`tests/customer-summary.test.ts` 验证策略和报告；HTTP/CLI 审批夹具覆盖 v3、历史 v2 阻断、样本改动及两轮混用。
- 网页审阅入口读取服务端结论：旧点估计与只做正确性测试的记录不显示新的批准按钮，报告解释缺少的依据；已有批准与交付仍分别显示。报告中的验证通过保持原实验含义，不因新门禁回写为失败。
- 现有 Runner 对被测库摘要进行检查，但评价器与 benchmark 的可执行文件摘要目前由评价程序报告，系统尚未独立从目标机文件核验；冻结前的二进制元数据和公开脱敏归档仍待完善。
- 统计区间依赖固定采样与分块假设，固定测量顺序仍可能产生系统偏差。没有本轮目标机 A/A 重复实验或人工对照，不能宣称误报率已校准或给出新增性能收益。

### 恢复、持久化和空候选

- **恢复**：查询全部处于活动或需对账的工作流，不受网页列表 200 条分页限制；Workflow 与 Task 的中断写入同事务，损坏的任务引用单独记录问题，不影响其他任务或改写已有批准。待核对的远端作业保留原 ID。
- **事务**：任务创建同时保存 Task、Workflow 和请求身份；同一请求竞争时复用已保存的结果。复现创建同时保存实验与其工作流引用；旧版本留下的未确认孤儿可在复现说明中看到，须按原 ID 核对 Runner，不能自动重发。
- **空候选**：提交与 checkpoint 共用源码筛选，仅有明确识别的未跟踪构建产物时拒绝创建候选或实验。Git 已提交但会话未保存时重用原 commit、tree 与哈希清单；旧记录缺少恢复依据则保留现场并明确报错。该筛选目前不是所有构建系统产物的完整识别器。
- **验证范围**：以独立临时 Git/SQLite 和本机 HTTP 夹具注入崩溃、重复请求、超 200 条记录、旧孤儿与恢复；集成后的相关 Node 测试 33/33 通过。网页对旧口径按钮、最新复验及完整审批交付夹具的针对性测试 3/3 通过；不访问真实 Runner、不执行真实人工批准或交付。
